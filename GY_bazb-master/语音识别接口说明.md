# 语音识别接口说明

## 接口说明

该接口用于接收前端上传的音频文件或音频地址，后端调用大模型语音识别服务后，将识别出的文本返回给前端。

后端固定使用 `model_config` 表中 `id=3` 的配置进行识别，前端无需关心模型配置。

## 请求地址

```text
POST /bazb/big_model/audio_transcription
```

## 请求方式

```text
POST
```

## 请求类型

优先使用：

```text
multipart/form-data
```

## 请求参数

| 参数名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `file` | `File` | 否 | 上传的音频文件，推荐使用该方式 |
| `file_url` | `string` | 否 | 音频文件公网可访问地址 |
| `audio_url` | `string` | 否 | 音频地址兼容字段，作用同 `file_url` |
| `language` | `string` | 否 | 语言代码，例如 `zh`、`en`，不传则自动识别 |

参数规则：

- `file`、`file_url`、`audio_url` 三者至少传一个
- 如果同时传了 `file` 和 URL，后端优先使用 `file`

## 请求示例

### 1. 上传音频文件

```javascript
const formData = new FormData();
formData.append('file', file);
formData.append('language', 'zh');

const res = await request.post('/bazb/big_model/audio_transcription', formData, {
  headers: {
    'Content-Type': 'multipart/form-data'
  }
});
```

### 2. 传音频 URL

```javascript
const formData = new FormData();
formData.append('file_url', 'https://example.com/test.mp3');
formData.append('language', 'zh');

const res = await request.post('/api/big_model/audio_transcription', formData, {
  headers: {
    'Content-Type': 'multipart/form-data'
  }
});
```

### 3. 兼容字段传音频 URL

```javascript
await request.post('/bazb/big_model/audio_transcription', {
  audio_url: 'https://example.com/test.mp3',
  language: 'zh'
});
```

## 成功返回示例

```json
{
  "code": 200,
  "msg": "识别成功",
  "data": {
    "text": "患者主诉胸闷三天，加重一天。",
    "language": "zh",
    "segments": [],
    "api_time": 1.25
  },
  "time": 1740000000
}
```

## 返回参数说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `int` | 业务状态码，`200` 表示成功 |
| `msg` | `string` | 返回消息 |
| `data.text` | `string` | 语音识别后的完整文本 |
| `data.language` | `string` | 识别出的语言代码 |
| `data.segments` | `array` | 分段识别结果，模型返回时会携带 |
| `data.api_time` | `float` | 后端调用模型耗时，单位秒 |
| `time` | `int` | 服务端当前时间戳 |

## 失败返回示例

### 1. 未传音频

```json
{
  "code": 4001,
  "msg": "音频文件不能为空",
  "data": {},
  "time": 1740000000
}
```

### 2. 上传文件无效

```json
{
  "code": 4002,
  "msg": "上传音频文件无效",
  "data": {},
  "time": 1740000000
}
```

### 3. 模型调用失败

```json
{
  "code": 500,
  "msg": "语音识别失败: xxx",
  "data": {},
  "time": 1740000000
}
```

## 前端接入建议

- 优先使用 `file` 上传音频文件，兼容性最好
- 若无法直接上传文件，可使用 `file_url` 或 `audio_url`
- `language` 不确定时可不传，由后端自动识别
- 建议前端在识别过程中显示加载状态
- 页面展示识别结果时，直接读取 `res.data.data.text`

## 备注

- 当前后端已对接 Gitee AI 的语音识别接口
- 后端路由已接入完成，无需前端再传模型名
- 若后续新增字幕、分段时间戳等展示需求，可直接使用 `data.segments`
